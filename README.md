# Global Student Migration – EDA

## Project Overview

This project explores global student migration data using Exploratory Data Analysis (EDA) with Python.

## Objectives

* Analyze student migration trends.
* Identify popular destination countries.
* Explore student enrollment patterns over time.
* Understand the factors influencing student migration.

## Tools and Libraries

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

## Project File

* `EDA migration (3).ipynb` – Jupyter Notebook containing data analysis and visualizations.

## Visualizations

* Bar charts
* Count plots
* Histograms
* Pie charts
* Heatmaps

## Conclusion

This project uses data visualization and analysis to understand global student migration patterns.
